# GoodFood v1.5 (build 1.5.3)

Bilingual (EN/GR) food scanner: health score, Nutri-Score, NOVA, additives, EU claims check,
comparison table with prices, healthier alternatives, history, read aloud, manual scoring,
and offline storage of products (IndexedDB) with import/export.

Always opens on the Welcome screen. On launch it removes old service workers and old caches.

Upload all files to the repository root: index.html, sw.js, manifest.webmanifest, icon.svg, .nojekyll, README.md.
GitHub Pages: Deploy from a branch, main, /(root).

For a future release, change "1.5.3" in index.html (3 places), sw.js and manifest.webmanifest.
